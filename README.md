# Семейный бюджет

Небольшое веб-приложение для учета семейных финансов: доходы, расходы, фильтрация, баланс, диаграмма и экспорт в CSV.

## Что уже реализовано

- Приветственный лендинг-блок на главной странице.
- Функциональный модуль учета бюджета.
- Добавление и удаление операций.
- Фильтрация по типу и категории.
- Подсчет доходов, расходов и баланса.
- Круговая диаграмма (Chart.js).
- Экспорт данных в CSV.
- Переключение светлой/темной темы.
- Сохранение данных и темы в `localStorage`.

## Как запустить

1. Откройте файл `index.html` в браузере (приветственная страница).
2. Нажмите кнопку перехода к калькулятору или откройте `app.html` напрямую.
3. Для комфортной разработки можно использовать Live Server в Cursor/VS Code.

## Идеи для развития

- Валидация полей с подробными сообщениями об ошибках.
- Редактирование уже созданной операции.
- Дополнительные графики по категориям и по месяцам.
- Импорт данных из CSV/JSON.
